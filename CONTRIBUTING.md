# Contributing to Enterprise Shield

Спасибо за интерес к проекту!

## Как помочь

- **Баги**: открывай [Issue](https://github.com/EnterPC-Core/EnterpriseShield-Android/issues) — опиши, что не работает, модель телефона, версию Android и приложения, шаги для воспроизведения. Логи (Настройки → Журнал) сильно помогают.
- **Идеи**: предлагай в Issues или в Telegram-боте.
- **Код**: форк → ветка → pull request.

## Правила для PR

1. Одна логичная вещь на PR.
2. Сборка должна проходить: `./gradlew assembleRelease`.
3. По возможности — тесты на новую логику.
4. Не включай секреты, ключи, токены, приватные конфиги в коммиты.

## Сборка

Требуется JDK 17 и Android SDK. См. README.

## Стиль

Kotlin по официальному стилю, комментарии по-русски допустимы (проект русскоязычный).
